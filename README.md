# BRX EduNexa

BRX EduNexa is a global education management platform by BRX.

## Supported Institutions

- Schools
- Private Schools
- Colleges
- Universities
- Coaching Institutes
- Training Institutes
- Online Academies
- Other Educational Organizations

## Core Hierarchy

Super Admin
→ Institution
→ Head / Admin
→ Teacher
→ Class / Section / Batch / Course
→ Student
→ Parent / Guardian

## Platforms

- Web
- Android
- iOS

## Core Technology

- Web: Next.js + TypeScript
- Mobile: Flutter
- Backend: NestJS + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Cache / Queue: Redis
- Storage: S3-compatible object storage
